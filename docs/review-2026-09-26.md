# uFlow review — 2026-09-26

Reviewed the working tree relative to `1caf8f2`, including the untracked source,
launcher manifests, tests and tools. The recent work is uncommitted, so Git does
not independently identify its author. Existing changes were preserved.
GitHub's open-issue search for `haimbilia/uFlow` returned no open issues on this
date. The unresolved items below come from the implementation and project notes.

## Corrections

| Area | Finding and correction |
|---|---|
| Wii VC conversion | Launch Options exposed a converter that labels decrypted Wii partition data as encrypted, matching the documented WiiFlow crash. Disabled that option and blocked both fresh and legacy cached launches. The internal converter also refuses plaintext partitions before creating output. Actual re-encryption is still open. |
| Wii VC USB source validation | The companion builder stopped at the first missing file and accepted the preceding partial image. It now reads the NFS header, requires every expected numbered chunk and its minimum length, rejects I/O failures, and bounds extents to the FAT data region. |
| Wii VC handoff lifecycle | The IOS HAI arm survived prepared-launch cancellation, an unrelated next executable and SD homebrew preparation. Those boundaries now disarm it, while the intended USB game's executable startup retains it. |
| Launcher persistence | An installed NooDS module overrode a user's explicit reassignment of that launcher to RetroArch. Reload now preserves the chosen module/core/bundle. Reproduced with a failing regression before the fix. |
| Invalid RetroArch modules | RetroArch's special readiness/launch paths skipped manifest errors, including duplicate IDs. Both paths now reject invalid modules. |
| RetroArch bundle metadata | Empty metadata could underflow the buffer; the final character was discarded without a terminating newline; positive INI error-line results were accepted as success. Parsing now uses an owned terminated string, requires a nonempty successful parse, and refuses provider-unmount failure. |
| RetroArch paths | The app accepted uppercase `.RPX`/`.WUHB`, but the loader rejected them. The loader now agrees and accepts provider paths up to the actual mount-field limit. |
| Launch Options | Compatible launchers after the first five disappeared. The popup now scrolls through the complete list and maps touch selection to the visible rows. |
| Interrupted settings writes | New recoverable writes for VC mappings and injection profiles had readers that ignored the recovery file. Both readers now recover an interrupted replacement. |
| Multilingual names | Existing version-4 catalogs retained old folder-name fallbacks, bypassing the new Japanese metadata handling. Version 5 requests a fresh scan; Japanese metadata and cache migration are covered by host tests. |
| Release builds | Existing module dependencies referenced an experimental `/uflow` mount and broke the release script. Canonical builds now use a separate ignored `module/build-native` directory. |
| Documentation and tests | Corrected contradictory bridge status, the blanket RetroArch BIOS claim and unsupported attribution of the exit hang. Updated stale settings-test row/launcher assumptions and added failure-line diagnostics. |

## Verification and delivery

The review adds `tools/test-review-regressions.ps1`, including compiled production
RetroArch provider and HAI source code with mocked platform I/O under ASan/UBSan.
It also runs launcher registry, manifest, argument, installer/module agreement
and UTF-8 tests. Existing HAI mapping tests verify the locally available r569
firmware's instruction sites without changing the source firmware.

Additional validation covers raw USB/RPL dispatch and lifetime, FAT reads,
raw-loader cleanup/exit tracing, Menu return, FTPiiU lifecycle, Wii launch/input,
conversion cancellation, library/media/artwork, VC injection and recovery,
payload synchronization and signed update packaging. Visual checks use the
actual SDL renderer with Mesa/OpenGL and the project artwork fixtures.

Rebuilt outputs are `app/uFlow.wuhb`, `module/RPXLoadingModule.wms`,
`payload/00_mocha.rpx` and `native-installer/uFlow-Setup.wuhb`. The native installer
embeds the matched app and dependencies through `tools/sync-native-payload.py`.
Actual-bundle host installation tests exercise fresh installation, replacement,
component selection, preserved settings/saves and an unchanged rerun.

Host checks passed for the full bundle (mask 131071), core-only (0), PS1-only
(8192), and all RetroArch components (122880). Renderer checks passed for both
skins, all twelve cover layout/spacing combinations, scrolling launch options,
settings controls, paging and a 3,600-frame idle run. Japanese text passed with a
host CJK font; this does not verify the Wii U's font service. Test logs and visual
captures are under `artifacts/review-20260926`.

This review performs no console testing or SD deployment. No user card, ROM or
save is modified. The installer remains a local personal bundle, as required by
the project's release instructions. No commits, remote issue comments or public
release were created.
