# Content types

Open Settings > Library > Manage Content Types > Add Content Type.

Select Name or Extensions to edit text in the same window. Move around the keyboard with the D-pad/stick, press A to type, X to erase, Plus to accept, or B to cancel. Touch keys also work.

Choose the scanner (Wii U raw directories, Wii WBFS, GameCube ISO, or generic Files). Generic Files accepts comma-separated extensions, for example `.nds,.gba`. Choose a compatible launcher from the entries configured in Settings > Launchers. Automatic preserves the existing directory default. Emulator entries currently open the emulator's ROM browser; VC presets resolve a mapping to an already prepared injection. See [LAUNCHERS.md](LAUNCHERS.md) for setup and limitations. UWUVCI is a PC injection builder, not an on-console launcher adapter.

Enable or disable the type, set its rail position, then Save Type. Return to Library, add a directory, select the new Content Type, set depth and save. Use Scan Now. Add multiple directories to the same type as needed.

Under Media, add directories for covers, full sleeves, backgrounds, logos, previews or metadata, and select the custom type in Library. Match filenames to the title ID or game name. Preview indexing does not add video playback support.

Renaming preserves the stable library ID and media associations. Remove a type only after reassigning its content/media directories. Removing a type never deletes games. Disable the built-in Wii U type instead of removing it.
