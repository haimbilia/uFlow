# uFlow 2026.10.23.2 - disable privileged network debugging

**Security update: download and run uFlow Setup, then restart the console. The app-only download and automatic updater do NOT replace the affected Aroma modules.**

The bundled RPX loader previously started IOSU TCP diagnostics automatically with IP filtering disabled. This diagnostic connection accepted commands as well as transmitting logs. This release removes the startup call and the TCP discovery, connection and command implementation from the bundled Mocha payload. The TCP-start IPC request is rejected. The legacy WUP server and devkit network bridge are excluded from the payload build.

- Both corrected modules are mandatory Core replacements in Setup, regardless of optional component selection.
- Existing settings, games and saves are preserved. Do not restore older loader/Mocha modules after updating.
- Local/USB logging remains; remote IOSU diagnostic capture is unavailable.
- Includes the installed-title discovery and installation handoff fixes from 2026.10.23.1.

Validation: built ARM symbols and loader object references checked; packaged modules pinned against stale builds; native payload selection and fresh-install/reinstall checks. Console boot and game-launch testing of this security rebuild remains pending. This is a targeted fix for the identified IOSU debugging services, not a security audit of every bundled component.
