# uFlow 2026.11.7

- Only Glass Flow and Retro Deck are bundled. Existing settings, installed skins, ROMs and saves are preserved on reinstall.

Changes since 2026.10.26.1 include integrated Bloopair controller management, input routing improvements, more accurate cartridge/disc/case models, shared launch animations, per-content-type case dimensions and material color, system-specific fallback sleeves, artwork matching improvements, asynchronous settings writes and media/browser improvements. Downloadable skins include The Collection, Switch Light, Switch Dark, uForce Experience and Afterglow.

Validation and limitations: host tests and native installer fresh/reinstall checks are recorded with the release. These do not establish bug-free hardware behavior. The existing HOME/video stall investigation remains unresolved. A reported input lock after changing Wii/GameCube cover paths has not been reproduced on host and remains open. Use Setup for updated runtime modules/controller support; the in-app update replaces the application.
