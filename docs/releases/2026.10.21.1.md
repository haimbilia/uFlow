# uFlow 2026.10.21.1

- **Add new games** discovers new titles without clearing the existing library.
  It preserves offline entries and existing metadata, artwork and favorites.
- **Complete scan** is the explicit full-library scan, with a notice that large
  libraries can take a long time. **Refresh media** identifies the separate media
  operation in Settings.
- Wii WBFS files on FAT32 USB can launch through WiiFlow or USB Loader GX.
  Discovery reads the game ID and header and uses tagged folders for friendly
  names. Add new games can repair previously unidentified Wii entries. Cover art
  and descriptions still require the corresponding media files.
- The WiiFlow bridge resolves the requested file across mounted FAT partitions,
  retries USB initialization once when no FAT partition is mounted, and logs
  distinct mount, file, header and ID failures.

## Installation and updating

Download `uFlow-Setup.wuhb` for a fresh installation or to update the WiiFlow and
USB Loader GX backends. Copy it to `SD:/wiiu/apps/`, run Setup, review the selected
components, and reboot into Aroma after installation. Existing settings and saves
are preserved.

`uFlow.wuhb` and the signed automatic update replace **only the uFlow app**. They
include the scan changes, but do not install the updated Wii backends. Existing
SD-only backends need the new Setup before FAT32 USB launching will work.

## Console results and limits

Wii Sports (RSPE01) launched from a rear-port FAT32 thumb drive through both
WiiFlow and USB Loader GX in the user's setup with a Wii U-formatted SSD connected
at the front. Front-left failed for both launcher selections; front-right failed
for WiiFlow. Logs show the front-port attempts stopped at the shared WiiFlow
bridge because no FAT partition mounted, including after retry. The front-port
GX attempt did not reach USB Loader GX itself.

Use the rear port for FAT32 in this tested arrangement. These results do not
establish compatibility for every drive, game, port configuration or cIOS setup.
GameCube USB support is outside this release; its adapter remains SD-only.

Wii/GC/GX launch, USB probe, library and additive-scan host tests passed during
development. Release validation also covers the signed updater, packaging and
actual Core+Wii fresh installation/reinstallation. Earlier EUR/JPN hardware
validation limitations remain; this release does not claim to resolve them.
