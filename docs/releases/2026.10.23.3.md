# uFlow 2026.10.23.3 - About and Support reports

Settings now has a small info button at the bottom left, opening About & Support.

- Start problem recording, reproduce the issue, then choose **Send report**.
- **Yes / No** confirmation is required. A fresh report is saved on SD before uploading to Karotech.
- If sending fails, the message shows `SD:/wiiu/apps/uFlow/support-report.json`. Send that file from a PC instead.
- Successful uploads return a report ID. Include it with your support request and describe what happened.
- Reports contain build/module information, source configuration, counts and bounded logs. Path/address lines are omitted; logs may still name games. No ROMs, saves, keys or account files are collected.
- Recording starts off. Reports are private to Karotech administrators and expire after 90 days. No remote debugging listener or remote commands are added.

The app-only update includes this feature. Setup includes it for fresh installs and preserves settings, games and saves. **If you have not applied the 2026.10.23.2 security fix through Setup, run this Setup and restart. App-only updates cannot replace the affected boot modules.**

Validation: host collector/UI tests, upload-failure fallback, four skins, native app/Setup builds and actual Core/Core+Wii U fresh-install/reinstall checks. Development app deployment passed full readback. Console-to-server upload still awaits hardware confirmation.
