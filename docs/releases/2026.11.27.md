# uFlow 2026.11.27

- Load matching decrypted Wii U updates from a separate update folder, with base-file fallback and updated RPX/RPL code.
- Load matching decrypted DLC from its own folder. Fixed DLC title enumeration and per-content detection; both BOTW DLC packs were confirmed working on Wii U.
- Improved raw-game asset loading and native file I/O. BOTW loading/gameplay and DLC were tested on console; other games need individual validation.
- Keep original base files separate from updates and DLC, and retain the existing per-title save location.

Run the matching uFlow-Setup.wuhb and select Wii U support, then fully restart the console to install the updated runtime modules. The in-app update replaces the application only; it does not update these modules. Existing settings, games and saves are preserved.

See the Updates & DLC guide on https://karotech.io/uflow/ for folder examples and region/title matching. Do not merge updates or DLC into the base game.

GitHub source and binaries exclude Karo Cloud and the skin downloader. Normal official updates remain enabled and install the full official edition.

Known issue: intermittent HOME/menu freezes remain under investigation. This release does not claim to fix them. BOTW DLC recognition is confirmed on hardware; host build, update-signature and installer checks are recorded separately.
