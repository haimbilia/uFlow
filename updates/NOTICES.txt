uFlow 2026.09.20-test4 - personal console test build

Matching uFlow source, local patches, build recipes and tests:
https://github.com/haimbilia/uFlow/tree/bbec0b0

This test package contains uFlow and its embedded update helper. It does not contain
Nintendo VC bases, user ROMs, saved games, console tickets or private keys.
The personal GlassFlow background was supplied by the user, with embedded
metadata crediting Imora. No ownership or redistribution rights are claimed.
This is not a general-purpose public installer release.
