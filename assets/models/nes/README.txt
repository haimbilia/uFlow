NES cartridge geometry prepared from user-supplied Nes Cart.stl.

nes-cart: 600 triangles, intended for selected/nearby cartridges.
nes-cart-small: 300 triangles, intended for smaller distant cartridges.
STL: original coordinates, editable geometry; source units unspecified.
OBJ: centered, height 1, X right, Y up, Z depth; outward winding.
UFM: same geometry as OBJ in compact indexed binary; see preparation script for format.

Both meshes remain closed and consistently wound. Volume changes are below 0.25%.
These checks do not establish Wii U performance or texture quality.
The app embeds the indexed OBJ geometry via tools/embed-cartridge-model.py.
NES media layouts use the 600/300 triangle meshes with a projected front label.
Labels come from media/nes/labels and remain separate from full cartridge images.
The UFM files remain interchange assets; the console does not parse STL/OBJ/UFM.
Source provided by user; original license/provenance not supplied.

Material update: upright orthographic library pose, grip left/label right.
A reusable front/back procedural plastic atlas adds grain, channel relief and
recess edges without per-frame image generation. Preview/details use a single
entrance/exit turn; the sticker is hidden on the back. The mesh remains 3D.

2026-10-25 renderer refinement:
The OBJ models remain the compact source geometry. embed-cartridge-model.py
now compiles a BSP and stitches split edges for reliable recessed-face ordering.
The renderer uses the smaller resulting tree for both sizes (1000 triangles,
502 vertices). No runtime model parsing or partition construction.
nes_back_label.hpp embeds the shared rear caution sticker generated by
tools/make-nes-back-label.py. Front cartridge stickers preserve aspect ratio
and use the actual shorter label recess. Tall stickers with a short top strip
wrap over the top edge. Otherwise an existing game logo can supply the edge
label, aspect-fitted on charcoal. Box covers are not cartridge-label assets.
