# PS1 jewel case

Imported from the user-provided ps1-jewel-case.zip. Original FBX and textures are retained under source/; no ownership or redistribution license is inferred.

The supplied mesh has 20 vertices and 26 triangles. Its UVs and material assignments are preserved. Shell and disc textures are reduced to 512 and 256 pixels and embedded in the app, so fresh installs do not need external model files. Disc artwork replaces the default disc texture; its UV rotation completes every 3000 ms during media showcase/details.

Regenerate with `python tools/prepare-ps1-jewel.py "assets/models/ps1/source/source/PSX Jewel Case.fbx" assets/models/ps1`.
